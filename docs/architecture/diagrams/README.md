# Architecture Diagrams

This directory contains Mermaid diagrams for JudicAIta's architecture.

## How to View

These diagrams use Mermaid syntax. They can be viewed in:
- GitHub (renders automatically in markdown)
- VS Code with Mermaid extension
- Mermaid Live Editor: https://mermaid.live

## Diagrams

- [system_architecture.md](system_architecture.md) - High-level system architecture
- [data_flow.md](data_flow.md) - Data flow through the system
- [training_pipeline.md](training_pipeline.md) - GRPO training pipeline
